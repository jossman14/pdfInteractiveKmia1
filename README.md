# PDF Interaktif Kimia: Titrasi Asam Basa

Flipbook HTML5 interaktif berjudul **"Titrasi Asam Basa"**, hasil ekspor Flip PDF Professional 2.4.9.26 (FlipBuilder).

## Isi

- `index.html`: halaman utama flipbook.
- `mobile/`: player HTML5 (JavaScript, CSS, ikon).
- `files/`: halaman buku (`mobile/`, `thumb/`, `basic-html/`), indeks pencarian, dan konfigurasi halaman.

## Cara Menjalankan

Buka `index.html` di browser. Bila ada fitur yang tidak termuat karena pembatasan file lokal, sajikan lewat web server statis, misalnya `python -m http.server`.
